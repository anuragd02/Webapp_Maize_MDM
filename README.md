# Maize Leaf Disease Classification Dashboard (MDM) 🌽

An AI-powered deep learning dashboard for detecting **Maize Downy Mildew (MDM)** using image-based disease classification.

The system uses a VGG16-based TensorFlow model to analyze uploaded maize leaf images and classify them as:

* Healthy
* Maize Downy Mildew (MDM) Infected

The platform provides:

* Automated disease detection
* Confidence-based prediction
* Fungicide advisory recommendations
* Severity-based treatment guidance
* Seed treatment and foliar spray recommendations

The project is designed to support early disease diagnosis, reduce crop losses, and assist farmers and researchers with data-driven disease management strategies.

Built using:

* Python
* Streamlit
* TensorFlow
* NumPy
* PIL
